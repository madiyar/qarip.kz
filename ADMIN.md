# Локальная админка

Та же админка, что на qarip.app/admin, но запускается на своём компьютере.
Отличия от веб-версии:

- файлы любого размера до 50 МБ, без ошибки «Failed to fetch»;
- при запуске сама скачивает свежую версию сайта;
- после каждого «Save» сама отправляет изменения на сайт (он обновится через 2–3 минуты).

Git знать не нужно.

## Каждый раз

1. Дважды кликните **`admin.cmd`** (Windows) или **`admin.command`** (Mac) в папке `qarip.kz`.
   Откроется чёрное окно и вкладка браузера с админкой.
2. Нажмите **Work with Local Repository** и выберите папку `qarip.kz`.
   Chrome спросит разрешение на изменение файлов — нажмите «Разрешить».
3. Работайте как обычно. После «Save» в чёрном окне появится
   «✓ Отправлено» — значит, изменения ушли на сайт.
4. Закончили — закройте вкладку, потом чёрное окно.

Чёрное окно не закрывайте, пока работаете: именно оно отправляет изменения на сайт.
Если закрыли раньше времени — ничего не потеряется, всё уйдёт при следующем запуске.

Браузер нужен **Chrome** или **Edge**. В Safari и Firefox локальный режим не работает.

## Что значат сообщения в чёрном окне

| Сообщение | Что делать |
| --- | --- |
| ✓ Отправлено | Всё хорошо |
| Не удалось отправить на сайт… Попробую ещё раз через минуту | Проверьте интернет. Окно повторит само |
| Кто-то другой одновременно изменил ту же запись… ветка conflict/… | Ваша версия сохранена, Мадияр её посмотрит. Обновите страницу админки (F5) и продолжайте |
| …ваши правки нельзя отправить автоматически… Напишите Мадияру | Напишите Мадияру, ничего не удаляйте |

## Один раз: установка

Это делает Мадияр (или вместе с ним), минут 10.

1. Установить **Git**: https://git-scm.com — все настройки по умолчанию.
2. Установить **Node.js** (версию LTS): https://nodejs.org — все настройки по умолчанию.
3. Скачать репозиторий. В «Документах» правый клик → «Open Git Bash here», затем:

   ```bash
   git clone https://github.com/madiyar/qarip.kz.git
   ```

4. Запустить `admin.cmd` и сохранить любую мелочь. При первой отправке откроется окно
   входа в GitHub: войти аккаунтом, у которого есть доступ к `madiyar/qarip.kz`.
   Больше вход не понадобится.
5. Для удобства: правый клик по `admin.cmd` → «Отправить» → «Рабочий стол (создать ярлык)».

На Mac в шаге 3 вместо Git Bash — «Терминал».
При первом запуске `admin.command` macOS может не дать его открыть: правый клик → «Открыть».
